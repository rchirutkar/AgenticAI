Notes:

Memory is need to get the context back to conversation otherwise it will be bad support.
Memory have two types:
1. Episodic Memory - only 10 messages in chat. Small and recent like chat messages.
2. Short term Memory - compressed summary of the pressent chat session. Compact and durable like session memory.
3. Long term Memory(RAG)
4. Operational Data(Memory) - in DB available which is changing

This memory is limited because of LLM contextual limitation.

Rolling Window:
Recency Rolling window - Clear old chat and
